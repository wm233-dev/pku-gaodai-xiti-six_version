## 答题空位（可调）

每道题后都留有空白用于书写解答：顶层题按类型分为证明题 5.5cm、计算题 3.5cm、其他 4.5cm；小题每道 2.2cm。
共同的题干和作答要求放在小题之前；仅用于列出已知条件的编号项不单独留空，统一在完整题目之后留答题空位。
长度在 `main.tex` 顶部这一段里调整（改数字即可，重新编译两次生效）：

```latex
\newlength{\ansprooflen}\setlength{\ansprooflen}{5.5cm}
\newlength{\anscomputelen}\setlength{\anscomputelen}{3.5cm}
\newlength{\ansgenerallen}\setlength{\ansgenerallen}{4.5cm}
\newlength{\anssublen}\setlength{\anssublen}{2.2cm}
```

如果想给某一道题单独加空位，直接在该题内容后加一行 `\ansgap{8cm}` 即可。
